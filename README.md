# The Daily life of the Computer Science student

The story starts with the player becoming a first-year Computer Science student at KMUTT's School of Information Technology (SIT). The player then experiences humorous choices and consequences inspired by student life.

## Installation

```bash
javac Main.java
```

## Usage

```java
java Main
```
